# 快译浮窗 · 在评论框旁，把中文想法写成自然英文

**想说什么已经很清楚，卡住的是怎么用英文说出来。**

QuickEnglish 是一个 macOS 菜单栏小工具：快捷键呼出，输入中文，补一句语境，生成英文并复制。适合写帖子、参与讨论、回复评论时使用。

## 为什么做这个

这个工具最初的需求很具体：在电脑上写英文帖子和评论时，希望可以先用中文表达自己的意思，再根据语境变成地道的英文。

只做逐字翻译，经常解决不了“这句话在评论里会不会太正式”“回复对方该怎么接话”。每次切到聊天窗口、重新描述要求，又会打断正在参与的讨论。所以把常用的三种表达方式和一个语境框放进随叫随到的浮窗里，让英文表达接得上原来的思路。

## 能帮你做什么

| 模式 | 适合的场景 |
|---|---|
| 自然帖文 | 把中文想法整理成自然的英文帖子，保留原意和个人语气 |
| 简短评论 | 把回应写得简洁、口语化，适合评论区和讨论串 |
| 忠实翻译 | 尽量保留原文信息和细节，不做额外发挥 |

语境框可填写“回复同行，表示部分赞同”“回复客户，友好但不承诺时间”。工具不会自动读取你正在看的帖子，需自己提供必要背景。

生成结果流式显示，默认自动复制；最后由你检查并粘贴到目标应用，工具没有自动发帖功能。

## 一个具体例子

中文输入：

> 我也遇到过这个问题。我后来把步骤拆小了，才比较容易坚持。

语境：

> 回复一位分享学习困难的网友，语气自然，不要像在教训对方。

选择“简短评论”。你期待的是类似这样的表达（人工示例，实际结果由模型生成）：

> I've run into this too. Breaking it into smaller steps made it easier for me to stick with it.

更多例子见 [使用示例](examples/replies.md)。

## 安装与第一次使用

需要 **macOS 13 或更新版本**。源码使用系统 AppKit/WebKit，不需要 Node.js；从源码构建需要已安装 Xcode Command Line Tools 和 `clang`。

在仓库目录运行：

```sh
./build.sh
open "build/快译浮窗.app"
```

构建脚本使用本地临时签名，这不是经过 Apple 公证的安装包。仓库历史中包含开发时的构建目录，建议按上述步骤在自己的 Mac 上构建。

1. 在设置里选择接口提供方，填写自己的 API 地址、可用模型名和 API Key。
2. 按 `Control + Option + E` 呼出浮窗；快捷键可以在设置里修改。
3. 输入中文，按需补充语境，选择表达模式。
4. 按 `Command + Enter` 生成，核对后回到原应用粘贴。

设置还可以控制自动复制和开机自动启动。

## 模型、费用和数据

- 支持 OpenAI、DeepSeek、Ollama 和自定义 OpenAI 兼容接口。预设模型名称来自开发时配置，使用前请确认自己的提供方仍支持它。
- **不提供作者的 API 或免费额度。** 使用者自行配置接口、承担调用费用。
- 选择云端接口时，中文原文和填写的语境会发送给该接口。选择本机 Ollama 时，需要自己先运行对应服务和模型。
- API Key 保存在本机用户配置目录的权限为 `600` 的文件中；不是仓库配置。不要提交该文件或把密钥贴进 Issue。
- 自动复制会覆盖当前剪贴板内容，可在设置中关闭。

模型可能改变语气或误解意思，涉及名字、金额、承诺时请逐项核对。
