# 从中文想法到英文表达

以下是人工编写的使用示例，不是固定输出，也不是模型实测记录。

## 参与讨论

- 中文：我理解你的意思，不过对刚开始的人来说，这一步可能太复杂了。
- 模式：简短评论。
- 语境：在技术社区回复别人，部分同意，友好地补充意见。
- 参考表达：I see what you mean, but this step might be a bit much for someone just starting out.

## 写自己的帖子

- 中文：今天终于把这个小工具跑起来了。功能还很简单，但已经解决了我每天都遇到的一个麻烦。
- 模式：自然帖文。
- 语境：分享个人进展，简洁，不要加营销口号。
- 参考表达：Finally got this little tool running today. It's still pretty basic, but it already solves a problem I run into every day.

## 回复客户

- 中文：资料我收到了，我会先检查完整性，缺什么再跟你确认。
- 模式：忠实翻译。
- 语境：回复客户，友好专业，不添加截止时间或结果保证。
- 参考表达：I've received the documents. I'll check that everything is complete and let you know if anything is missing.

生成后检查是否添加了原文没有的承诺。浮窗默认复制结果，但最终是否发送由你决定。
